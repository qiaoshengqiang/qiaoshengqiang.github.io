# 苍穹突击 SKY STRIKER 3D

three.js 纵向卷轴 3D 空战射击游戏，零外部素材——所有模型、纹理、音效与音乐全部程序化生成。

## 启动

```bash
cd sky-striker
python3 -m http.server 8090
# 打开 http://127.0.0.1:8090
```

（需通过 HTTP 访问，ES Module 不能直接双击 index.html 打开）

## 操作

| 输入 | 作用 |
|---|---|
| 鼠标移动 / WASD·方向键 | 机体机动 |
| 空格 / 鼠标左键 | 机炮连射 |
| X / 鼠标右键 | 追踪导弹（自动锁定） |
| Z / L | 清屏炸弹 |
| Shift | 加力冲刺 |
| Ctrl | 减速 |
| Esc / P | 暂停 |

## 内容

- **6 个关卡场景**：蓝色海岸线 → 赤色峡谷 → 霓虹夜城 → 雷暴之眼（动态闪电）→ 极光平流层（着色器极光）→ 深空前线（行星/星云/小行星带）
- **6 个 Boss**：钢鲸重型轰炸机 / 沙蝎沙漠炮舰 / 夜刃隐形翼（隐身+冲刺）/ 雷神浮空堡垒（激光走廊）/ 极光之翼双子歼击机 / 创世方舟终极母舰（三阶段、装甲开合、激光扫射）
- **8 种敌方单位**：无人机编队、截击机（环绕射击）、炮舰、自爆机、悬浮炮台、导弹护卫舰、水雷、王牌（桶滚机动）
- **程序化 BGM**：每个关卡独立的调式/节奏/配器；Boss 战自动切换更急促的变奏；菜单/通关/失败各有主题曲
- **系统**：连击倍率、火力升级（3 级）、锁定框、雷达、补给（P/M/B/H/S）、存档（最高分与关卡解锁）

## 调试参数

`?level=3` 直接进入第 3 关 · `&boss=1` 跳过杂兵直达 Boss · `&god=1` 无敌

## 技术栈

three.js 0.180（本地 vendor，无 CDN 依赖）+ 原生 ES Modules + WebAudio 程序化音频。
