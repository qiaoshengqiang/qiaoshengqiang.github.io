# ASCII 逃生（第一版原型）

封闭房间 + 一只直线乱窜、越来越快的怪物 `g` 的 ASCII 生存小游戏，纯原生 HTML/JS，零依赖。

## 启动

直接双击 `index.html`（或右键用浏览器打开）即可，无需构建、无需服务器。手机浏览器打开同样可玩（画面自动缩放 + 触屏方向盘，竖屏体验最佳）。

若不喜欢 `file://` 也可以：

```bash
cd ascii-survival && python3 -m http.server 8000
# 浏览器打开 http://localhost:8000/
```

调试可复现的一局：`index.html?seed=123`

## 操作

| 按键 | 作用 |
|---|---|
| 方向键 / WASD | 移动一格（开始游戏） |
| R | 任何时候重新开始（新地图） |
| 回车 / 空格 | 结算画面重新开始 |
| 1 / 2 / 3 / 4 | 标题或结算画面选房间大小（特小 18×10 / 小 30×16 / 中 40×18 / 大 50×22）并开新局 |
| 触屏：滑动 / 画面拖动 | 移动（手机自动出现）：轻甩一步，按住拖动每 30px 一步 |
| 触屏：右下方向盘 ▲◀▶▼ | 移动：单击一步，按住每 130ms 连走 |
| 触屏：右下按钮条 | 标题/结算画面换房间大小、重开（进行中隐藏防误触） |

## 规则与回合顺序

玩家每按一次方向键 = **1 回合**，固定顺序执行：

1. **玩家半场**：尝试移动 1 格；撞墙则原地不动（回合照样消耗，且不计步）。
2. 若目标格是怪物 → 接触判定：护盾就绪则双方**交换位置**、怪物掉头、护盾进入冷却、本回合怪物停走；冷却中 → 游戏结束。
3. 只有**成功移动**计步：步数 +1、护盾冷却 −1（撞墙不回充护盾——这是防挂机的关键）。
4. **怪物半场**：开始时**提前规划**本回合每一格的走向，然后按计划逐格执行——
   - 下一格是墙 → 规划时即时反弹换向；
   - 下一格是玩家 → 执行时逐格接触判定（护盾就绪：怪物不进玩家格、原地掉头、本回合停走；冷却中：游戏结束）；
   - **主动变向（步级节奏）**：节奏以“步”倒数（`M_DIR_MIN~M_DIR_MAX`，默认 3~8 步），倒数归零的
     **那一步**直接改走随机新方向（优先侧向、不即时 180° 回头、只挑可通行方向），
     同一回合内可以变向多次。玩家无法靠“回合边界”预测转向点；被护盾跳过的半场不消耗节奏。
5. 逐格执行保证怪物不可能一脚跨过玩家。

难度曲线：怪物速度 = `2 + floor(回合数/20)`（`SPEED_RAMP=20`），**无上限**——每 20 回合 +1 格，半小时局面上千回合时速度可达三位数。因为回合只在玩家按键时推进，挂机不按键就冻结局面，但**原地撞墙刷回合不会回充护盾**，护盾耗尽后必死，所以躲避是必须的。

速度无上限后的渲染对策：怪物动画**按总时长预算分批播放**（`ui.js` 的 `ANIM_BUDGET=360ms`、`MAX_ANIM_TICKS=24`）——低速（≤8 格/回合）仍是逐格 45ms 不变；高速时一次渲染 tick 合并走多格（碰撞判定仍逐格发生），所以无论速度多高，每回合动画都不会超过约 360ms，输入不会被卡住。

## 调参

- `game.js` 顶部 `CFG`：速度曲线（`SPEED_START/RAMP`，无上限）、护盾冷却（`SHIELD_CD`）、怪物主动变向间隔（`M_DIR_MIN/M_DIR_MAX`，单位 = 怪物步数，默认 3~8）。
- `game.js` 的 `MAP_SIZES`：四档房间尺寸（内部格数、障碍块数、最小出生距离），默认"特小"。
- `ui.js` 顶部：字号/行高与怪物动画参数（`ANIM_BUDGET` 总时长预算 / `MAX_ANIM_TICKS` 批数上限）。

## 文件结构

- `game.js` —— 纯逻辑层（无 DOM），参数与回合顺序全在这里
- `ui.js` —— 渲染 + 键盘 + 逐格动画（本身不含游戏规则）
- `index.html` —— 页面骨架
- `test.js` —— Node 自动化测试：`node test.js`（失败时退出码非 0）

## 测试

```bash
node test.js
```

覆盖：随机地图四档尺寸 × 各 150 次生成校验（尺寸/出生合法/不重叠/距离/全联通/**障碍确实生成**——防 BFS 尺寸引用退化）、撞墙语义、护盾冷却按步回充、速度曲线无上限（含长局大数值断言）、变向下沉到步级（预生成 plan、倒计时步归零的步变向、一回合内两次变向、未到点整回合直线）、走廊逐格碰撞（怪物不可越过玩家）、护盾抵挡与掉头、玩家撞怪交换、冷却中接触即死、30 局 × 400 回合模糊测试（每回合校验玩家/怪物不嵌墙、不重叠；fuzz 内天然含高速度场景）。

## 已知限制（原型的范围）

- 单只怪物、无追踪 AI（随机直线 + 节奏变向 + 撞墙反弹），存在偶然的"运气局"。
- 故意不按键可冻结局面（回合制特性），但护盾耗尽后原地蹭回合必死。
- 无音效、无存档、无背包/成长/多道具——按第一版范围刻意不做。
