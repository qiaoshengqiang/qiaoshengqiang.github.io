# NEON RUNNER // 霓虹疾驰

一个可直接打开游玩的 three.js 赛博朋克城市赛车原型。单圈约 **2.8 km**，依次穿过街道、高架、跨海光桥、地下隧道、废弃工业区和霓虹广场；支持键盘、触控、计时圈速、AI 对手、障碍碰撞、氮气、漂移、镜头切换、暂停/重开与程序化音效。

> **状态：PROTOTYPE READY**  
> 无构建步骤；推荐使用 Chrome / Edge 直接打开 `index.html`。

---

## 1. 快速开始

1. 打开本目录下的 **`index.html`**（双击即可，支持 `file://` 直接运行）。
2. 推荐 Chrome / Edge；需要 WebGL。
3. 点击 **START RACE**，或按 `Enter`。首次点击/按键后浏览器才会允许启动 AudioContext。
4. 倒计时结束后按住油门出发。完成 **3 圈**即可进入成绩页。

可选本地服务器（与直接打开等效，便于开发调试）：

```bash
cd <本目录>
python3 -m http.server 8080
# 打开 http://127.0.0.1:8080/index.html
```

无任何 CDN、网络字体或外部素材请求；断网、`file://` 均可运行。

## 2. 操作

### 键盘

| 输入 | 功能 |
|---|---|
| `W` / `↑` | 油门 |
| `S` / `↓` | 刹车；低速时倒车 |
| `A` `D` / `←` `→` | 转向 |
| `Space` | 漂移 / 手刹 |
| `Shift` | N₂O 氮气加速 |
| `C` | 切换镜头：CHASE → CINEMA → HOOD |
| `R` | 比赛中把车复位到赛道中心（保留当前圈计时） |
| `P` / `Esc` | 暂停 / 继续 |
| `M` | 音效开关 |
| `Enter` | 主菜单开始比赛 |

### 触控 / 移动端

- 左下 `◀` / `▶`：转向。
- 右下 `BRAKE` / `GAS`：刹车 / 油门。
- 右下 `N₂O` / `DRIFT`：氮气 / 漂移。
- 右上 `Ⅱ`：暂停；暂停页提供继续、重开、回正、退出。
- 触控 HUD 使用安全分区：竖屏为紧凑数字速度卡片，横屏保留完整圆形速度表；控件与信息面板不重叠、不出屏。

品质（HIGH / LOW）与音效可在主菜单切换。LOW 会降低像素比、Bloom 强度和关闭 FXAA，适合低性能设备。

## 3. 比赛结构

- **3 圈**，单圈约 2.8 km，闭合城市环线。
- 玩家与 **4 名 AI 对手**同场，起跑时位于最后一排，HUD 显示实时名次 `P1–P5`。
- 过起跑线后开始计圈；HUD 显示当前圈时间、上一圈、最佳圈、圈数和名次。
- 每进入一个新路段会显示 **SECTOR 01–06** 提示并播放检查点音效；手机上即使路段胶囊被隐藏，也会通过 toast 告知当前路段。
- 跑完 3 圈进入成绩页：总时间、最佳圈、最高速度、名次、逐圈列表（最快圈/更快圈标签）。
- 最佳圈会写入 `localStorage`（键名 `nr.bestLap`），下次主菜单可见；存储不可用时自动降级，不影响游戏。

### 六段赛道

赛道由 **30 个控制点、闭合 Catmull-Rom 曲线**生成，所有路段共用同一条连续路面，不需要加载或传送。

| # | 英文名 | 中文 | 特征 |
|---|---|---|---|
| 01 | NEON AVENUE | 霓虹大道 | 起跑直道、城市街区、湿滑反光路面、密集招牌 |
| 02 | SKYLINE FREEWAY | 高架动脉 | 持续爬升到约 24 m 高度，护栏、桥墩、远景塔楼 |
| 03 | ABYSS BRIDGE | 跨海光桥 | 高空粉色霓虹桥面，强风感与远景城市灯海 |
| 04 | UNDERPASS 09 | 地底环线 | 穿过隧道入口下降到负高度，琥珀色隧道灯、封闭空间 |
| 05 | RUST YARDS | 废弃工业区 | 绿色工业照明、仓库/集装箱轮廓、粗糙路面氛围 |
| 06 | NEON PLAZA | 霓虹广场 | 终点前的品红霓虹广场与看板，回到起跑直道 |

高架、桥、隧道入口和出口都通过高度与路面法线平滑衔接；没有独立场景切换。

## 4. 玩法系统

### 驾驶与手感

- 自定义轻量车辆物理：油门/刹车/倒车、速度相关转向、侧向抓地、手刹漂移、坡度影响、空气阻力。
- 转向使用阻尼插值，低速不失控；高速转向角自动收窄。
- 漂移时降低侧向抓地并增加转向角，松开后逐渐恢复；持续漂移会累计漂移分数并弹出 `DRIFT +N`。
- 车辆被限制在赛道横向边界内；撞墙会移除向外速度并擦除部分速度，不产生夸张反弹。
- 速度上限：常规约 82 单位/秒，氮气约 101；HUD 以 km/h 显示。

### 氮气

- 初始 100；按住 Shift / N₂O 时以 25/s 消耗，提供额外推力与更高极速。
- 松开后以 4.5/s 回充；漂移时 12/s 回充。
- 低于 18 时 HUD 氮气条进入低量警示；耗尽时弹出提示。

### 障碍与碰撞

- 赛道沿途布置 8 个程序化障碍：护栏、混凝土块、油桶、检查门。
- 圆形碰撞体 + 推离 + 速度衰减；碰撞触发火花、烟雾、屏幕红色 damage flash、镜头震动和 `IMPACT // HAZARD` toast。
- 与 AI 车辆接触也会推离、减速并产生接触提示。
- 没有生命值/车辆损毁系统；碰撞是街机式惩罚，不会直接结束比赛。

### AI 与名次

- 4 名 AI 沿赛道进度行驶，带车道摆动和弯道预判减速。
- 简单橡皮筋：落后玩家过多时略微提速，领先过多时略微收油，保持比赛张力。
- AI 也会完成 3 圈；成绩页按完赛顺序与时间计算名次。

### 辅助提示

- 逆行检测与 `WRONG WAY` HUD/大字提示。
- 暂停页显示当前圈数、当前圈时间、名次。
- 退出到主菜单会复位车辆和比赛状态；重开从发车格重新倒计时。

## 5. 视觉与声音

### 视觉

- 自定义霓虹天空 Shader、指数雾、湿地反光、霓虹边缘光。
- 640 栋建筑使用 `InstancedMesh` 批量绘制；程序化楼体窗格、招牌、灯树和城市光晕。
- 后处理链：`RenderPass → UnrealBloomPass → FXAA → gamma`；Bloom 提供霓虹溢光，gamma pass 补偿线性空间亮度。
- 雨丝、速度线、漂移胎痕、碰撞火花、烟雾、氮气尾焰、屏幕速度暗角与镜头震动。
- 三种镜头：追尾、电影远景、车头视角；会根据速度拉远、增加 FOV 和抖动。
- 结果页/暂停页有独立暗色玻璃面板；短横屏和窄竖屏有专门紧凑布局。

### 声音

- 全部程序化生成，无外部音频文件：
  - 引擎 4 层振荡器 + 软饱和 + 转速/油门映射低通、排气噪声、涡轮啸叫、路面滚动、风噪、雨声、轮胎打滑、氮气喷流；
  - 换挡点火切断/排气回火、氮气接合冲击、碰撞、检查点、圈速、倒计时、UI 音效；
  - 120 BPM 前瞻调度的合成器音乐。
- 首次用户手势后才创建/恢复 AudioContext；`M` 或菜单按钮静音；暂停时降低引擎/环境声。

## 6. 技术实现

### 运行方式

- three.js **r128**，非模块化全局 `THREE`；所有游戏脚本按顺序用 `<script>` 加载。
- 后处理所需 shader/pass 已放入 `js/vendor/`，因此无需 npm、打包器或 CDN，直接打开 `file://` 也能运行。
- 无外部图片/模型/音频依赖；纹理均由 Canvas 程序化生成。

### 关键模块

| 文件 | 职责 |
|---|---|
| `js/util.js` | `NR` 命名空间、数学/随机工具、程序化 Canvas 纹理、调色板、六路段定义、CubeEnv |
| `js/track.js` | 30 控制点闭合曲线、1600 采样、切线/右向量/坡度/曲率预计算、`query` 局部窗口查询、路段范围、道路/护栏/起跑门/隧道等场景构建 |
| `js/environment.js` | 天空、雾、建筑 InstancedMesh、霓虹招牌、灯树、城市光晕、起跑灯、按弯道方向摆放的横向箭头弯道牌 |
| `js/car.js` | 程序化玩家/AI 赛车：楔形车身、翼子板、前铲/侧裙/扩散器、双层尾翼、双排气、LED 灯组、座舱内饰、五辐轮毂/刹车盘/固定卡钳、车号圆牌与车牌；静态零件按材质合并；`createObstacle` 生成护栏/块/油桶/门 |
| `js/effects.js` | 火花、烟雾、光尘、雨、速度线、胎痕、碰撞/漂移/氮气特效、镜头 shake、质量分级 |
| `js/audio.js` | `AudioEngine`：引擎、风、雨、打滑、氮气、碰撞、倒计时、UI、合成器音乐 |
| `js/game.js` | 初始化、状态机、物理、碰撞、AI、计时、HUD、镜头、输入、暂停/重开/退出、成绩页 |
| `css/style.css` | 菜单/HUD/暂停/结果页、霓虹样式、响应式触控安全区、短横屏/窄竖屏适配 |
| `index.html` | 画布、HUD、菜单、倒计时、暂停、结果、加载/错误层、触控控件、脚本顺序 |

### 赛道查询与物理

- 曲线预采样 `N = 1600`，每点缓存位置、切线、右向量、坡度和曲率。
- `track.query(pos, hint)` 优先在上一采样点附近 ±40 的局部窗口搜索，避免每帧全局扫描；当距离过大时回退到全局搜索。
- 路面半宽 `10.5`，车辆横向碰撞限制 `9.92`；车辆高度贴合当前路面 `groundY`。
- 帧间隔上限 0.05 s，防止切后台后穿透；速度/NaN 有兜底。
- 碰撞在车辆位置更新后处理，再重新查询赛道，避免被推出路面。

### 性能策略

- 建筑批量 InstancedMesh；关闭阴影；Bloom + FXAA 可切 LOW。
- 像素比限制：桌面/移动高分屏最高 1.55（低功耗设备 1.25），LOW 为 1。
- 速度表 Canvas 在竖屏触控小屏隐藏，改用 DOM 数字，减少每帧绘制。
- 实测 headful Chrome 在 1366×768、390×844、844×390 均为约 **60 FPS**（测试机，HIGH 品质）。

## 9. 已知限制 / 下一轮可做

1. **AI 不是完整赛车 AI**：使用赛道进度 + 车道摆动 + 简单弯道减速 + 橡皮筋；没有真正的超车规划、障碍规避或车辆间物理避让。
2. **碰撞是街机式圆形近似**：没有车体变形、零件损坏或耐久度；障碍物是静态摆放，没有动态交通。
3. **圈速验证**：3 圈完赛路径通过测试注入边界完成；未记录真人手动 3 圈成绩。单圈长度约 2.8 km，正常一圈约 40 秒。
4. **移动端功能取舍**：竖屏隐藏圆形速度表（保留数字速度卡），窄屏隐藏路段胶囊（进入路段时用 toast 提示）；触屏没有镜头切换和 R 回正，但暂停页可回正。
5. **外设/辅助**：无手柄支持、按键重映射、幽灵车、回放或排行榜。
6. **浏览器差异**：Chrome/Edge 验证最充分；Firefox/Safari 依赖 WebGL 与 AudioContext 实现，`file://` 下的 localStorage 可能受浏览器安全策略限制（游戏会安全降级，最佳圈可能不持久）。
7. **LOW 品质**会关闭 FXAA 并降低 Bloom/像素比，画面会更硬、更省性能。

### 建议下一轮

- 加入带避障/超车意图的 AI，以及动态车流和更丰富的障碍组合；
- 车辆损伤/冒烟/性能衰减，增加风险回报；
- 完整手动 3 圈试玩与圈速调参（尤其高架入口和隧道出口）；
- 手柄、按键重映射、移动端镜头按钮；
- 时间挑战/幽灵车、排行榜、每日赛道；
- 更细的接触阴影、路面积水反射和更高质量的隧道体积光。
