## 1. 反馈问题与修复

### 1.1 控制键左右反了 ✅

**根因**：游戏世界的前进方向是 `+Z`，偏航角增大时车头转向世界 `+X`；而追尾相机看向 `+Z` 时，屏幕右方实际是 `-X`。旧代码把 `D / →` 映射为 `steer = +1`，于是车实际向屏幕左侧转。

**修复**（`js/game.js`）：

```js
const steerTarget = canDrive
  ? ((input.left ? 1 : 0) - (input.right ? 1 : 0))
  : 0;
```

`player.steer` 的符号同时驱动物理偏航、前轮转角、车身侧倾、相机外摆与镜头预瞄，因此只需在输入层翻转一次，整套表现保持一致。键盘与触控共用同一输入对象，移动端同步修复。

**实测**：按住 `D` 约 1.1 s：

- 偏航角变化 `Δyaw = -0.746 rad`（屏幕右转）；
- 沿相机右向量的速度增量 `+18.22`；
- `player.steer = -1.00`，前轮同步指向右侧。

### 1.2 赛道指向标志竖着朝上 ✅

**根因**：路边弯道牌使用 `chevronTexture()` 绘制的是“向上”的 V 形箭头，且朝向未与弯道方向关联。

**修复**：

- 新增方向化纹理 `NR.chevronTexture(color, dir)`：箭头改为**横向**左/右指向的三联 V 形；
- 每块牌根据前方 12 个采样点的**有符号转向**判断左弯/右弯；
- 牌子放到弯道**外侧**（`lat = -turn * 12.6`）；
- 箭头指向车辆必须转向的一侧（左弯指左、右弯指右）；
- 隧道口立柱另用新的 `NR.hazardStripeTexture()` 斜纹，不再和方向牌共用纹理；
- 移除隧道墙面文字中的 `▲`，避免任何“向上箭头”的歧义。

**实测**：场景中共 22 块弯道牌（4 块左弯牌 + 18 块右弯牌），逐块读取实例矩阵、牌面局部轴和赛道切线后校验，**22/22 箭头方向与弯道方向一致**；21 块位于弯道外侧，1 块位于回环接缝附近。

### 1.3 赛车跑起来时的音效 ✅

**旧问题**：引擎只有两个低频率振荡器直接过低通，声音薄、发闷；换挡时音高突变但没有机械反馈，缺少排气、涡轮和路面速度感。

**新引擎声音层**（`js/audio.js`）：

- 4 层振荡器：基频锯齿、上八度锯齿（微失谐）、高次谐波锯齿、次低音正弦；
- `WaveShaper` 软饱和，产生机械咆哮而非单薄蜂鸣；
- 转速/车速/油门共同映射音高与低通截止（实测行驶中基频约 `210 Hz`、截止约 `2.87 kHz`）；
- 独立**排气噪声**层，随转速与油门调制；
- **涡轮/进气啸叫**，氮气时明显增强；
- **路面滚动噪声**，随速度提升；
- 风噪、雨声、漂移胎噪保留并重新平衡；
- **换挡检测**：转速骤降时触发短暂点火切断 + 排气“砰”声；
- **氮气点火**：增压接合瞬间有额外高频冲击；
- **倒计时空踩油门**：修复了倒计时转速被主循环覆盖的问题，起跑前可拉转速（车速保持 0）；
- 暂停时引擎、滚动、风噪、胎噪一起淡出，不会残留。

**实测**：真实驾驶中 `AudioContext.state = running`；引擎总线增益 `0.19–0.20`、基频 `124–210 Hz`、滤波截止 `1976–2866 Hz`；主输出采样 `RMS 0.0525 / peak 0.137`，低频、中频、高频均有能量；换挡事件被实际触发。倒计时按住 W：基频 `90.6 → 152.8 Hz`、增益 `0 → 0.145`，车速保持 `0`。无音频相关报错。

### 1.4 赛车模型与细节 ✅

`js/car.js` 已重写为更完整的程序化赛博赛车，同时保持低 draw call：

- **车身**：楔形主 hull、隆起的四轮翼子板、发动机盖中脊、导流槽、前铲、侧裙、侧进气、后扩散器与 5 片垂直鳍；
- **空气动力学**：双层尾翼、端板、鹅颈支架、前翼刀；
- **动力细节**：双出排气与发光尾嘴、氮气火焰与尾焰光晕；
- **灯组**：贴合鼻锥斜面的 LED 日行灯带、竖向 DRL、前雾灯、贯穿式尾灯、竖向尾灯钩、雨灯；
- **座舱**：仪表台、两张桶椅、头枕、方向盘、车手头盔、A 柱，透过半透明座舱玻璃可见；
- **车轮**：轮胎、五辐轮毂、中心盖、发光轮圈、刹车盘、**不随轮旋转的卡钳**；
- **外观标识**：左右车门 `07` 号码圆牌、车尾 `NR-2087 // 07` 车牌、车顶赛车条纹、侧裙霓虹饰条、后视镜与镜面灯；
- **性能处理**：静态零件按材质合并（`mergeTransformed`），每辆车仅约 **30 个网格 / 4.4k 三角形**，5 辆车同场仍有充足性能余量。

玩家与 4 名 AI 使用不同车号（07 / 12 / 23 / 31 / 44）和配色；刹车时刹车盘发光增强，尾灯变亮，氮气/漂移时底盘灯变色。

### 1.5 附加修正：完赛排名一致性

完赛后 HUD 排名与结果页名次可能不一致：`computeRank()` 没有把玩家完赛时间纳入与 AI 相同的比较公式。现在玩家与 AI 都按“完赛时间越早排名越高”计算，并在 `finishRace()` 中同步 `game.rank = place`。三圈自动驾驶实测结果页 `P2` 与 HUD/内部排名一致。

## 2. 运行方式

直接双击 `index.html` 即可（`file://` 可用），或启动静态服务器：

```bash
cd <本目录>
python3 -m http.server 8080
# http://127.0.0.1:8080/index.html
```

- 无构建步骤；无 CDN、网络字体或外部素材请求；
- three.js r128 与后处理 pass 位于 `js/vendor/`；
- 推荐 Chrome / Edge；需要 WebGL；
- 首次点击 START 或按 Enter 后才启动 AudioContext。

## 6. 已知限制

- AI 仍是“沿赛道进度 + 车道摆动 + 橡皮筋”的街机 AI，没有主动超车或障碍避让；
- 碰撞使用圆形/半径近似，没有 OBB 车体或可变形车损；
- 三圈验证由真实物理自动驾驶完成，尚未由真人手动连续跑完 3 圈，难度与圈速仍建议试玩调校；
- 音频在真实 Chrome 中通过节点状态与波形采样验证，未做主观听感试听；
- 极端 320×480 视口下暂停弹窗高度仍略高于屏幕，但全部操作按钮在屏内；
- 范围外：手柄、幽灵车、在线排行榜、车辆选择、赛后回放。
