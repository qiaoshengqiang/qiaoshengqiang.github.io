# MÖBIUS GP

> 只有一面的赛道。踩下油门，别问哪边是上。

一款直接运行在浏览器里的 3D 莫比乌斯环竞速游戏，使用 **Three.js** 构建。九条可选赛道、五车同场、三圈决胜；每跑完一圈，赛道都会把你翻到另一面。五条进阶赛道带有实体中央隔离带的分叉路段，走哪一侧由你在入弯前决定。

## 快速开始

需要 **Node.js 18+**，无需安装任何依赖。

```bash
cd mobius-gp
npm start
```

或者直接双击 **`启动游戏.command`**（macOS）。服务器会自动选择空闲端口并打开浏览器。

也可以手动启动：

```bash
node server.mjs --open     # 启动并打开浏览器
node server.mjs            # 仅启动服务器
npm run serve              # 同上
```

> 不要直接双击 `index.html`。游戏使用 ES Modules 与 import map，需要通过本地 HTTP 服务器访问。

## 特性

- **真正的参数化莫比乌斯赛道**：路面由 `(u, s)` 参数曲面生成，车辆、相机与护栏都对齐曲面切空间；完成一圈后车辆自然处于赛道背面。
- **完整比赛流程**：菜单预览、赛道/难度/涂装选择、倒计时灯、三圈比赛、AI 对手、圈速、排名、结算、暂停、重开与主菜单。
- **驾驶手感**：基于曲面测地曲率的横向力模型。离心力、轮胎抓地与转向力共同决定车辆会不会被推向外侧，弯道必须真的刹车、转向，不能靠赛道自动带你过弯；另有漂移蓄力与释放、氮气、加速带、撞墙/隔离带回弹、车身侧倾与悬挂压缩。
- **分叉走线**：五条赛道共九处分叉，左右两条路线拥有不同宽度、弯心与加速带。HUD 会在入弯前提示当前选择，底盘灯与地面导流线标明分叉方向；AI 会提前选边并在隔离带出现后坚持所选线路。
- **有压迫感的对手**：AI 以曲率前瞻计算每个弯的极限速度，带横向速度前馈、超车换线与早期分叉决策。困难难度下 AI 拥有更高的直线速度与弯道抓地力，会主动压迫你的走线。
- **视觉**：UnrealBloom 后处理、ACES 色调映射、星空/星云/行星、全息广告牌、动态起跑灯、粒子尾焰与漂移烟。
- **声音**：完全由 Web Audio 实时合成——引擎、轮胎、风声、氮气、倒计时、结算音效，无外部音频文件。
- **本地记录**：按赛道保存最佳单圈；声音开关与难度自动记忆。
- **移动端适配**：触屏按键、安全区适配、竖屏与横屏布局、自适应渲染分辨率。
- **零构建、零 CDN、可离线运行**：Three.js 与字体均已放入项目内。

## 技术说明

- 赛道中心线为圆形，横向坐标 `s ∈ [-width/2, width/2]`，扭转角为 `twists · u / 2`；路面高度与径向偏移叠加低阶正弦起伏。赛道没有“内外侧”之分，只有连续的单面。
- 车辆位置用赛道参数 `(u, s)` 表示，物理在世界坐标中计算后再投影回曲面，避免在翻转处出现万向锁与朝向跳变。
- 路宽不是常数：`widthAt(u)` 在分叉前后平滑加宽，`islandHalfAt(u)` 控制中央实体隔离带的起落；护栏、灯柱、广告牌和加速带全部跟随动态路宽布局。
- 玩家横向物理使用 `-curvature · v · |v|` 的离心加速度、有限抓地力、速度相关转向力与横向阻尼。转向不足会撞外侧护栏，转向过度会滑向内侧，弯速由物理决定。
- 相机使用曲面基向量构造 up 向量，因此在赛道背面仍然保持正确构图；追尾、近距、车头三种视角可切换。
- AI 沿赛车线行驶，按前瞻曲率、抓地力与刹车距离规划入弯速度，并用横向力前馈稳定走线；带难度系数、橡皮筋、超车换线与分叉选边，不会瞬移或穿过护栏。
- 分叉的 `branchWeight` 在路段两端平滑归零，保证加宽路面与主路无缝衔接；隔离带出现后，AI 会接受当前一侧并停止横穿尝试。
- 渲染分辨率会根据帧率自适应，移动端降低像素比与泛光强度；场景资源在切换赛道时完整释放。

## 浏览器支持

推荐最新版 Chrome、Edge、Safari 或 Firefox，需要 WebGL 2。桌面独立显卡可获得最佳画质；集成显卡与手机端会自动降低渲染分辨率。
